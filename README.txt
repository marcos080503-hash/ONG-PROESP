# Site institucional da PROESP Campinas

Projeto acadêmico estático em HTML, CSS e JavaScript.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador. Para uma experiência melhor, use a extensão Live Server do VS Code.
3. Navegue pelas páginas pelo menu.

## Arquivos
- `index.html`: página inicial
- `sobre.html`: história e apresentação
- `atuacao.html`: áreas de atuação
- `acoes.html`: iniciativas e campanhas
- `contato.html`: redes sociais e contato
- `styles.css`: estilos responsivos
- `script.js`: menu mobile
- `assets/`: imagens recortadas dos prints enviados pelo usuário

## Observações importantes
- As imagens foram recortadas dos prints do Instagram enviados para esta conversa; a resolução e a qualidade são limitadas pela captura de tela.
- O conteúdo é uma versão inicial demonstrativa. Revise os textos com a PROESP antes de publicar.
- Não há backend, banco de dados, login ou formulário de envio.
